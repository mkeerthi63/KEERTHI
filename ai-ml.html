RAG Customer Support Assistant

Answers customer questions about Zepto's delivery, refund, return, membership and gift-card policies, grounded only in 8 policy documents.

  • Generates answers with Llama 3.3 70B (Groq); output is validated against a Pydantic schema, retried with the validation error on failure, and cited sources are checked against what was retrieved.
  • Embeds documents with all-MiniLM-L6-v2 in ChromaDB: Hit@1 91.7%, Hit@3 100%, MRR 0.958 on 32 labeled queries.
  • Found the keyword router misrouted paraphrased questions; a hybrid keyword + semantic LangGraph router raised accuracy from 43.8% to 96.9%.
  • FastAPI /ask endpoint, Docker image, 6 Pytest unit tests with a mocked LLM client, and GitHub Actions CI.

Survival Prediction ML Pipeline

End-to-end classification pipeline on the 891-passenger Titanic dataset, from profiling to a serialized production pipeline.

  • Median imputation for missing age (19.9% of rows), mode for categoricals, one-hot encoding and scaling in a ColumnTransformer.
  • Compared Logistic Regression (ROC-AUC 0.852), Decision Tree (0.814) and Random Forest; tuned Random Forest reached accuracy 82.6%, F1 0.754, ROC-AUC 0.868.
  • GridSearchCV with 5-fold CV on F1; SMOTE lifted recall from 0.70 to 0.74 versus the baseline.
  • Fare regression side-model (MAE 18.87, RMSE 30.92) with residual analysis; full pipeline saved with joblib.

Water Quality Prediction

Forecasts six pollutant levels for 22 river monitoring stations so rising pollution can be flagged before the next lab sample. Started in the Shell-sponsored AICTE internship and extended afterwards.

  • 2,861 lab samples (2000–2021), evaluated on a time-based split: trained before 2018, tested on 2018–2021.
  • Error analysis showed station and year alone could not explain O2 or NO2, so I engineered per-station lag, rolling-mean, seasonal and sampling-gap features.
  • Compared a persistence baseline, Random Forest and a PyTorch MLP; the log-target Random Forest raised mean R² from 0.300 to 0.449 (CL 0.955, SO4 0.859).
  • Every experiment logged in MLflow; Streamlit app forecasts any station's next sample.
